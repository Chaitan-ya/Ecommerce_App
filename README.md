# Ecommerce_App

A modern, fast, full-featured mobile eCommerce application built with Expo (React Native), TypeScript, and Expo Router.

## Features
- **Modern UI & Micro-interactions**: Sleek, mobile-first design with smooth transitions and interactive navigation
- **Product Catalog**: Multi-category browsing, keyword search, price/rating sorting, and product specifications
- **Cart & Dynamic Pricing**: Real-time quantity updates, subtotal and delivery fee calculations, and instant promo code validation
- **Checkout & Address Selection**: Saved delivery addresses, new address input, and fast checkout flow
- **Simulated Payment & Order Tracking**: Multiple payment options (Cards, UPI, COD), instant order confirmation, and live order status tracker
- **Profile & Order History**: User profile, past orders with itemized views, and support shortcuts

## Tech Stack
- **Framework**: [Expo](https://expo.dev) (SDK 57) / [React Native](https://reactnative.dev)
- **Routing**: [Expo Router](https://docs.expo.dev/router/introduction)
- **Language**: TypeScript
- **Icons**: Lucide React Native
- **Animations & Layout**: React Native Reanimated & React Native Safe Area Context

## Getting Started

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npx expo start
```

### 4. Run on Platform
- **Android Emulator / Device**: Press `a` in terminal or run `npm run android`
- **iOS Simulator**: Press `i` in terminal or run `npm run ios`
- **Web**: Press `w` in terminal or run `npm run web`
